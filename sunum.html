Executive Summary

This project encompasses an end-to-end machine learning workflow for the automated recognition of handwritten digits (0-9). Logistic Regression and SVM models were optimized for maximum accuracy using 5-Fold Cross-Validation.

Industry Applications

Banking

Automated recognition and verification of numerical values on checks to reduce manual processing errors.

Logistics

ZIP code recognition via OCR systems for high-speed automated mail sorting and routing.

OCR Systems

Efficient digitization of physical archives, transforming scanned text and forms into structured database records.

The "Digits" Dataset

  • 1,797 Total Samples
  • 8x8 Pixel Grid structure per sample
  • 10 Distinct Classes (Digits from 0 to 9)
  • 64 Numerical Features (Grayscale intensity values)

Preprocessing & Reliability

Stratified Splitting

Implementing stratify=y guarantees that the training and test sets maintain the exact same proportion of each digit class, avoiding biased learning loops.

Standard Scaling

Pixel values were standardized using StandardScaler. Crucially, fitting was restricted to the training subset to strictly prevent Data Leakage.

5-Fold CV

To mathematically validate that model benchmarks were consistent and repeatable rather than coincidental, cross-validation evaluated across 5 separate splits.

Evaluation Insights

Confusion Matrix Analysis

An isolated audit of error distribution patterns revealed distinct characteristics:

  • 3 vs 8: Represented the most persistent classification conflict due to overlapping pixel density clusters within the center grid.
  • 1 vs 8: Occasional vertical orientation structural similarities triggered isolated margin failures.

By projecting feature spaces non-linearly, the SVM model resolved these high-dimensional boundaries where linear hyperplanes fell short.

Conclusion & Takeaways

  • SVM Superiority: For raw pixel matrix classifications, non-linear kernels consistently deliver a 2%-3% accuracy premium.
  • Pipeline Enforcement: Omitting proper feature scaling and stratified splitting leads directly to validation instability and structural overfitting.
  • Scalability: While SVM excelled on this benchmark, evaluating Deep Learning frameworks (CNNs) represents the natural progression for high-resolution arrays.
